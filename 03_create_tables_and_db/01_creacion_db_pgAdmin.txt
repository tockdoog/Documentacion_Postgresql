========================================
1️⃣ ¿QUÉ ES pgAdmin?
========================================

pgAdmin es la interfaz gráfica oficial de PostgreSQL.

Permite administrar PostgreSQL sin usar terminal.

Con pgAdmin puedes:

✅ Crear bases de datos
✅ Crear tablas
✅ Ejecutar SQL
✅ Administrar usuarios
✅ Ver relaciones
✅ Hacer backups

CREATE TABLE usuarios (
    id SERIAL PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE NOT NULL,
    password TEXT NOT NULL,

    creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

========================================
📖 EXPLICACIÓN
========================================

SERIAL
→ número automático.

PRIMARY KEY
→ identificador único.

VARCHAR(100)
→ texto máximo 100 caracteres.

NOT NULL
→ obligatorio.

UNIQUE
→ no permite repetidos.

DEFAULT
→ valor por defecto.

1️⃣8️⃣ CREAR RELACIONES ENTRE TABLAS
========================================

📌 Crear tabla productos:

CREATE TABLE productos (
    id SERIAL PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    precio NUMERIC(10,2) NOT NULL
);

----------------------------------------

📌 Crear tabla pedidos:

CREATE TABLE pedidos (
    id SERIAL PRIMARY KEY,

    usuario_id INTEGER NOT NULL,
    producto_id INTEGER NOT NULL,

    fecha TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT fk_usuario
    FOREIGN KEY(usuario_id)
    REFERENCES usuarios(id),

    CONSTRAINT fk_producto
    FOREIGN KEY(producto_id)
    REFERENCES productos(id)
);

========================================
📖 EXPLICACIÓN
========================================

FOREIGN KEY
→ crea relaciones.

REFERENCES
→ referencia otra tabla.

usuario_id
→ conectado con usuarios(id).

producto_id
→ conectado con productos(id).
